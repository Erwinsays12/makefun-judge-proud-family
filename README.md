## What it does

`main.py` writes one short family scene — warm, funny and heartfelt,
one line, under 280 characters — to `/output/entry.txt`. The scene is
fixed text, so the program is fully deterministic: no network, no
input, no randomness, no environment secrets.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
